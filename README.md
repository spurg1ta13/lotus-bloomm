# Lotus Bloom

**Lotus Bloom** is an informational beauty salon website featuring a showcase gallery and a detailed service price list.

🚀 **Live Demo:** [https://lotusbloom.gr](https://lotusbloom.gr)

---

## 🛠️ Technologies
- **Frontend:** React, TypeScript, Tailwind CSS, shadcn/ui
- **Build Tool:** Vite
- **AI Assisted Prototyping:** Lovable.dev
- **Hosting & Domain:** Vercel (Deployment) / Papaki.gr (Domain provider)

---

## 💻 Local Setup

```bash
# Clone repository
git clone [https://github.com/spurg1ta13/lotus-bloomm.git](https://github.com/spurg1ta13/lotus-bloomm.git)

# Install dependencies
npm install

# Run project
npm run dev
